# ERC-MP-Inverted-Pendulum-Ritwik
Submission for the ERC Inverted Pendulum Mini Project by Ritwik Sharma.

Studied basics of control systems and implemented a PID controller for control of cartpole environment of gymnasium by farama foundation. Also investigated optimal control strategies like LQR and attempted to make a very basic implementation of the same on hardware.

![Video Demonstration](https://github.com/user-attachments/assets/a0f95885-d6e2-4e77-a6cf-0e31250d6569)

The hardware implemention ultimately wasn't successful owing to lack of proper equipment for measuring angle of the pendulum and lack of a suitable motor for the project.
